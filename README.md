# CFSM-SAO 主题（修改版）

基于 WAOR/CFSM-SAO main 分支源码修改并重新构建。

## 改了什么

- 测速区 V4/V6 按运营商分组显示：
  - 每个运营商一组：`电信 延时 V4 206ms / V6 196ms`
  - 下面两行小进度条（7px，比原来小）：V4 一行、V6 一行
  - 丢包同理：`丢包 V4 1.0% / V6 93.3%` + 两行小柱
  - 没有 V4/V6 后缀的线路（如 BGP、Node 1）保持单独一组显示
- 有 V6 数据才显示 V6：某台机器只有 V4 时，不会出现空的 V6 行
- 悬浮查看每格数据的 tooltip 保留

## 取舍说明

- 原主题每行线路名是个可点击的"切换线路"按钮（访客可换探测目标），分组布局下这个按钮去掉了；
  站长仍可在面板设置页配置默认线路，不影响。
- 构建：`npm install && npm run build`（Node 24），产物即本目录的 `index.html` + `assets/`。

## 部署

用本目录的 `index.html` + `assets/` 整体替换当前主题文件即可（不要只拷 index.html，assets 文件名带 hash，已更新）。
